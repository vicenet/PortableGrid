Clean-up tools
Snap to grid

Moves the selection onto the nearest columns and rows; text snaps its first baseline to the baseline grid.

Grid check

Scores how much of the page sits on the grid and outlines everything that doesn't.

Type styles on the grid

Paragraph styles from a type scale (uses Body text size); every leading is a whole number of baselines.

Page layouts

Builds a magazine page on the grid: image frames, threaded text locked to the baseline grid, folios and editable PG paragraph styles. Set a baseline grid first for the best result.

Tools
Arrange selection into cells

Places the selected objects into the grid cells, in reading order.

Split selection into tiles

Cuts the selected artwork into one clipped tile per cell. Gutters become gaps.

Export tiles

Saves every cell as its own image, numbered in reading order: ideal for Instagram grids and carousels.

Settings & shortcuts
Illustrator menu commands

Adds Toggle grid, Snap, Snap and fit, and Grid check to File › Scripts, so they work without the panel. Give them keys with an Action (Insert Menu Item, then a function key).

Keyboard shortcuts (panel focused)

Alt+BackspaceClear grid
Alt+GShow / hide the grid
Alt+SSnap selection
